# Icon set licenses

This extension ships pre-rendered SVG data extracted from `react-icons@5.7.0`.
react-icons itself is MIT licensed, but **the icon artwork is not** -- each set
carries its own license, and redistributing the SVG data inside this extension
means those terms apply here too. Verify attribution requirements for every set
you keep before publishing to the Marketplace.

## Notes

- **CC BY 4.0** sets (Font Awesome, and others) require visible attribution.
- **MPL-2.0** (Circum Icons) is a file-level copyleft: the SVG data stays under MPL even when redistributed.
- Some sets forbid redistribution of modified artwork; the generator does not modify path data, only the wrapper `<svg>` attributes.
- If a set's terms are inconvenient, drop it from the generator and it disappears from the index and the bundle.
